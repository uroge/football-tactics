## Interfaces and ownership

- The TV analysis session owns consent, state, stop and resource lifetime. The Android platform adapter and deterministic lifecycle fixtures exercise the same observable start/stop behavior. A verified capture adapter supplies frame identity, time and geometry, with recorded replay as the second input adapter.
- The Mac analysis module takes a validated frame and explicit session state and returns typed observations. Live FastAPI and offline replay call the same interface. Detector, tracker, classifier and calibration state live inside the vision implementation, with narrow test interfaces for their independently measurable behavior.
- The shared protocol owns the wire schema, correlation, errors and timing invariants. The transport module keeps authentication, reconnection, heartbeats and bounded work behind that interface. TV acceptance checks exercise actual WebSocket and fixture replay. The overlay consumes frame-correlated annotations, current geometry and layer configuration. The TV owns age checks and window projection.
- Tactical calculations consume calibrated observations and yield typed, confidence-qualified annotations. The Android renderer owns display mapping and focus. Introduce a Rust adapter only after a candidate computation shows enough benefit to justify a second implementation.
